# Dokumentácia

Vitajte v dokumentácii projektu Tesla katalóg, pripravovaného archívu československej elektroniky.

## Začíname

V časti [Základy]({{< relref "zaklady" >}}) nájdete úvod do používania archívu. [Katalóg súčiastok]({{< relref "katalog-suciastok" >}}) je pripravený ako vstup do budúceho prehľadu súčiastok.

## Stav obsahu

Dokumentácia sa pripravuje. Ukážkové stránky sú výslovne označené a neslúžia ako technické údaje súčiastok.
